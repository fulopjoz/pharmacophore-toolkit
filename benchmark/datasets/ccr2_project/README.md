# CCR2 Project Set — DrugEx CCR2 Campaign

## Source

These are the actives and decoys used internally in the DrugEx CCR2 de-novo design project
for ROCS threshold sweeping and reinforcement-learning reward shaping.

| File | Rows | SMILES column | Description |
|------|------|---------------|-------------|
| `actives_ccr2_N75.csv` | 75 (74 valid) | `SMILES` | CCR2 actives from Papyrus / ChEMBL30 (pChEMBL ≥ 6, allosteric binding) |
| `decoys_ccr2_N500.csv` | 500 | `Smiles` | Property-matched decoys (DUD-E-style) |

Original location in repo:
```
tutorial/advanced/rocs/rocs_rl_ccr/rdkit_cdpkit/actives_decoys/
```

## Bias Warning

> **bias_suspect = true**

Decoys were generated by matching physicochemical properties (MW, LogP, HBD, HBA) to the actives
using a DUD-E-style approach. This method is known to introduce **analogue bias**
(topologically similar decoys can inflate enrichment metrics).

**Do NOT use this set as the primary benchmark for publication-quality enrichment comparisons.**
Use `ccr2_mubd` (max-unbiased, Xia et al. 2018) for unbiased assessment.
