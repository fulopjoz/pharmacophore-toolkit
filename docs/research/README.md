# Consensus Pharmacophore Research Hub

This folder contains research materials for optimizing consensus pharmacophore model generation.

## Structure

- **papers/**: Scientific papers on consensus pharmacophore methods
- **ideas/**: Notes, brainstorming sessions, and approach comparisons
- **benchmarks/**: Performance tests and optimization experiments

## Research Questions

1. Which consensus pharmacophore algorithm is fastest?
2. Which algorithm provides best virtual screening performance?
3. How to optimize clustering parameters (tolerance, occurrence threshold)?
4. Trade-offs between speed and accuracy?
